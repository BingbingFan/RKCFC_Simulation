# Caption split for every manuscript table:
# the caption keeps only the table's name, without a final period; the rest of
# what the caption used to say becomes the start of the note under the table.
# Read by R/table_captions.R, which both table generators source.
#
# One block per table:
#   @@ <id>
#   TITLE <the new caption; {{n}} inserts capture group n of MATCH>
#   MATCH <perl regex, anchored at the start of the caption the generator builds>
#   LEAD  <replaces the matched text at the head of the note; {{n}} as above>
# Whatever follows the match is kept word for word after LEAD. A caption that
# does not match its MATCH stops the build, so an edit to a caption in a
# generator cannot silently produce a wrong split.
#
# TITLE lines give a formal, precise title that states what is tabulated, for
# which methods, and under which conditions, in one sentence without a colon. MATCH and LEAD are
# unchanged, so the notes are unaffected.
